# CountingGloBiMap Analysis Notebooks

This directory contains Jupyter notebooks for analyzing CountingGloBiMap experiment results.

## Overview

These notebooks analyze the JSON output files generated by the C++ experiment executables. They provide visualizations, statistical analysis, and insights into the performance and accuracy of CountingGloBiMap configurations.

## Notebooks

### Dataset Experiments

- **test_datasets_for_k.ipynb** - Analyzes how different values of k (number of hash functions) affect accuracy and performance
- **test_datasets_new.ipynb** - Performance metrics analysis for various dataset sizes
- **test_datasets_full_time.ipynb** - Detailed timing benchmarks for insert and query operations
- **test_datasets_with_errord.ipynb** - Error detection analysis showing false positive rates and error magnitudes

### Polygon Experiments

- **test_polygon.ipynb** - Analysis of polygon rasterization experiments
- **test_polygons_mask.ipynb** - Polygon mask-based filtering analysis

### Resolution Analysis

- **resolutions.ipynb** - Multi-resolution analysis of spatial data
- **resolutions2.ipynb** - Bin size histogram analysis for different datasets
- **resolutions3.ipynb** - Dataset statistics across multiple resolutions

### Special Analysis

- **AbundanceR.ipynb** - Abundance/cardinality analysis for spatial features

## Usage

### Prerequisites

Install required Python packages:

```bash
pip install -r ../requirements.txt
```

Or install with extras:

```bash
pip install -e ".[notebooks]"
```

### Running Notebooks

1. Start Jupyter:
```bash
cd notebooks
jupyter notebook
```

2. Open any notebook and run cells

## Data Paths

**Important**: These notebooks expect experiment output files in specific directories. You may need to update paths if you've reorganized the project structure.

Common paths to check in notebooks:
- Experiment output directories (e.g., `../experiments/test_datasets/`)
- JSON result files
- HDF5 dataset paths (if using real datasets)

Most notebooks read from paths like:
```python
experiments_path = "/home/moritz/tf/globimap/experiments/"
```

You may want to update these to:
```python
experiments_path = "../experiments/"  # Relative to notebooks directory
```

## Generating New Data

To generate fresh experiment data for analysis:

1. Build the C++ executables:
```bash
cd ../build
cmake ..
make
```

2. Run experiments (examples):
```bash
./test_datasets
./test_datasets_new
./test_polygon
# etc.
```

3. JSON output files will be created in `../experiments/` directories

4. Open the corresponding notebook to visualize results

## Dependencies

These notebooks primarily use:
- **pandas** - Data manipulation
- **numpy** - Numerical operations
- **matplotlib** - Plotting
- **h5py** - HDF5 file reading (for some experiments)
- **geojson** - Polygon data handling (for polygon experiments)
- **tqdm** - Progress bars

## Notes

- Notebooks analyze C++ experiment outputs - they don't use the Python `counting_globimap` module directly
- Most analysis is post-processing of JSON result files
- Some notebooks may reference hardcoded dataset paths that you'll need to adapt to your environment
